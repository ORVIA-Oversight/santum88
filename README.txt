SANCTUM 88 LIVE PACK

Static deployable site. Upload the contents of this folder as a Vercel static project or commit to GitHub and import into Vercel.

Pages:
- index.html — master Sanctum 88 public site
- match.html — Sanctum Match
- profile.html — Sanctum Profile Studio
- membership.html — membership tiers
- private.html — public privacy/consent/standards summary
- onboarding.html — demo onboarding shell (no backend storage)

Important production gates before taking money or collecting sensitive data:
- legal/licensing/venue/insurance approval
- production privacy notice + DPIA
- verified adult/high-risk payment acquiring
- identity/age verification design
- secure authentication and product-scoped data permissions
- backend/form wiring and retention rules
- commercial price confirmation

This pack intentionally does not claim those controls are live.
